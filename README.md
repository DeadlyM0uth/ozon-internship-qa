# Поиск самого высокого супергероя

Программа получает героев из API и находит самого высокого по полу и наличию работы.

Запуск программы:

```bash
python main.py
```

Запуск юнит-тестов:

```bash
python -m unittest
``` 

Запуск интеграционного теста:

```bash
RUN_INTEGRATION_TESTS=1 python -m unittest test_integration.py
```

Запуск всех тестов:

```bash
RUN_INTEGRATION_TESTS=1 python -m unittest
```
